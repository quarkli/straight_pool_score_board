# 14.1 連續撞球計分室

繁體中文的 Straight Pool 計分與規則網頁，部署於 GitHub Pages：
https://quarkli.github.io/straight_pool_score_board/

## 功能

- 記住球員姓名、目標分數、開球球員；自動保存進行中的比賽。
- 每局合法進球、一般犯規、洗袋、開球失誤、適時警告後的三犯追加罰分；可分段記錄跨球堆長局。
- 負分、撤銷、達標判勝、認輸、逐局紀錄。
- 12 個擺位情境，含重排 14／15 顆、母球或子球干涉排球區、頭點被擋、洗袋與全子球在頭線後。
- 球員勝率、最高連續得分、每局進球、犯規率、對戰篩選及分數走勢。
- JSON 匯入／匯出；支援 File System Access API 的瀏覽器可選擇本機 JSON 檔，於本分頁持續更新。

## 執行與測試

無第三方依賴，需 Node.js 22+ 與 Python 3。

```sh
npm test
npm start
```

開啟 http://localhost:4173 。請使用 HTTP 伺服器，ES modules 不支援直接開啟 file://。

## 記分方式

每筆輸入是同一局「尚未記錄的合法進球」，可整局輸入或選擇「繼續此局」分段累加。犯規那一桿進球不可列入；之前合法進球保留。合法進球會清除先前連犯，因此「先進球再犯規」是新的一犯。開球失誤扣 2 分，不計入連犯；第三次一般犯規必須勾選「此桿前已告知兩犯」才追加 15 分，並由犯規者重開。

統計每局進球以合法進球除以上場次數，含零分局；逐筆表格的相同球員／局次表示同一局的分段記錄。

## 儲存與隱私

GitHub Pages 是靜態主機，不能直接在伺服器或儲存庫寫 JSON。資料保存在 `localStorage`，不會上傳到 GitHub，也不會跨裝置同步。請下載 JSON 保存；跨裝置可匯入。自動備份檔案需每次開頁重新授權，選檔會寫入目前完整紀錄，請選擇專用備份檔。匯入僅合併新 ID，衝突保留本機原記錄，不靜默覆蓋。

不要以多個分頁同時記分；偵測到其他分頁更新後需重新整理。清除站台資料會刪除本機歷史，但不影響已下載的 JSON。

## 失誤與防守統計

「數據分析」及本場計分頁新增失誤換手次數／比率、零進球局、安全球次數、可評估安全球數、被得分率、平均失分、未失分率，以及對手下一局犯規率。

失誤換手率以已結束局數為分母，不是逐桿命中率。安全球後的觀察窗口是對手緊接著的完整一局，會合併分段與跨球堆進球；沒有下一局或對手的局尚未完成（包括中途認輸）不列入評估。失分以合法進球計，不扣對手犯規分數。被得分與對手犯規都是結果觀察，不直接判定防守品質或因果。

舊版 schemaVersion 1 JSON 可直接回算，不必轉換。記分時，零分換手也應記錄，並區分失誤、安全球與犯規；合法的防守開球請以安全球記錄。

## 全螢幕記分板與計時（新版）

記分板固定在視窗內，左右選手與總分、中央交換位置按鈕；中央母球代表零分，1–15 號球代表本次新增的合法進球數，點選對應選手側數字後會反白 1 至該數字，再選擇安全球、失誤不進、犯規或繼續本局。左右交換只改畫面位置，不改球員身份或出桿順序。雙方紀錄區可獨立捲動，以分隔線區分上場局，最後顯示（本局淨得分／失誤不進次數／出手次數）。

出手次數預設每顆合法進球一桿，再加換手最後一桿；分段續打不加最後一桿。多球同桿、特殊進球或其他情況請展開記分視窗的「出手次數與備註」修正，避免統計失真。舊紀錄缺少次數則顯示未記錄，不自行推測。

比賽開始即計時；休息暫停，繼續後恢復，換手自動結算雙方有效用時。現在時間為裝置本地時間，與比賽計時分開。未按休息即關閉網頁，計時仍持續。撤銷只更正記分，保留已耗用時間並暫停計時，需確認後手動繼續。

兩犯時會提示先口頭告知球員；確認已告知後，第三次一般犯規自動扣 1 分並追加 15 分，犯規者重新開球。未達開球碰岸要求的開球犯規扣 2 分；符合要求後另有一般犯規扣 1 分，不能將所有開球洗袋都一律扣 2 分。

「對局歷史」預設顯示全部記錄，可用開始日期範圍、選手及對手過濾。每場以先攻在上、後攻在下呈現，列出開始／結束時間、有效用時、比分、局數、最高連進、每局平均、失誤、安全球、犯規、出手數、個人用時、平均出手得分、平均出手用時及失誤率。平均出手得分以淨得分計，失誤率只計失誤不進，安全球與犯規另外統計。

球員總體分析的出手指標只使用有記錄出手次數的樣本，用時平均只使用有計時的樣本。中途開始計時的場次不列入完整場次的時間平均，舊紀錄不會被當成零秒。JSON 維持 schemaVersion 1，相容舊版記錄。

## 10 場 70 分模擬對局

在「對局歷史」按「載入 10 場模擬對局」，或開啟 `?demo=1#history`，會合併載入 10 場固定模擬紀錄，保留既有比賽並依 ID 避免重複。每場標示「模擬」，日期為 2026-11-12 至 2026-11-21，包含四名虛構選手、不同比分、進攻失誤、安全球、一般犯規、開球犯規、三犯追加扣分、計時與休息。

`demo-games.json` 可直接下載後匯入。用 `node generate-demo.mjs` 可重建相同對戰事件與比分。統計頁會包含載入的模擬對局，因此正式分析前請確認資料來源。

### 開球選擇與 14／15 分摘要

開局時兩側皆可記分，第一次確認保存的球員自動成為開球者；取消記分不會鎖定。此後非擊球側按鈕隱藏，左右交換仍不改出桿順序。記錄 14／15 分，或同一局累積至 14／15 顆時，顯示本局得分、失誤、出手、用時與總分摘要，5 秒後自動關閉；可提前關閉。

中央球號兩側的選項改為白色圓點，不另顯示數字；選中範圍以亮白圓點標示。非擊球側圓點整列隱藏，只有尚未記分的開局兩側皆顯示。

記分操作與結果標記分開呈現：目前擊球側以空心白圈供點選；非擊球側沒有記分按鈕，但仍以實心白圓顯示最近一次上場局的合法進球數（最多對應 15 格）。零分換手不會抹除同局之前已得分的圓點，已結束比賽也會保留雙方結果。

### 中央球號累計記分與修正

只有全場第一次記分時，左右兩側各顯示 0–15 的白圈按鈕以選擇開球者。第一筆保存後側邊僅保留實心結果圓點，所有記分改為點中央球號；球號是該局球堆的累計進球位置。例如左側記至 3，右側記至 6，實際各得 3 分，歸屬為左側 1–3、右側 4–6。母球仍代表本次新增零分。

換手不清除兩側歸屬；記至 14／15 顆時顯示雙方本局摘要，5 秒後（或提前關閉）清空該球堆標記，開始下一局。修正按鈕回退上一筆，連同分數、擊球順序與該筆球位歸屬恢復；保留已用時間，原本計時中則繼續，原本休息則保持暫停。
